# Website Performance Lead Analyzer

Python project that identifies slow business websites and generates qualified leads for web performance optimization.

## Features

- Google Maps data collection via Apify
- Website detection
- WordPress detection
- Lighthouse API performance analysis
- Email extraction
- Lead scoring system

## Tech Stack

- Python
- REST APIs
- Data analysis

## Use Case

The tool automatically identifies companies with slow websites and collects contact information, enabling targeted outreach for web performance optimization services.
